# Dataset

Archivo: `breast_cancer.csv`

Fuente en Kaggle: [Breast Cancer Wisconsin (Diagnostic)](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data)

Fuente original: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)

El dataset tiene 569 registros y 30 variables numéricas. La variable `diagnosis` indica si el caso es benigno (`B`) o maligno (`M`). La columna `id` solo se utiliza para identificar las predicciones.
